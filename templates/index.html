What's actually simulated

  • k-Factor (PULSES/UNIT) calibration: overwrite a prover quantity, the register backs out a new k-Factor exactly per the manual's formula
  • VCF temperature compensation across all 9 documented types (Linear, API 24/54/54B/6B/54C/54D, NH3), with the documented Tmin/Tmax domain check (VCF DOMAIN ERROR outside range)
  • A real Pt100 RTD curve (IEC 60751), so the temperature reading, the +/-0.3°C field-adjustment ceiling, and the 100Ω±20Ω continuity check are all internally consistent
  • Multi-point calibration's duplicate-flow-rate and adjacent-0.25% validation rules
  • A background pulser thread reproducing the exact J8 #32/#33/#34 fault-voltage signatures for idle / stalled / good-flow conditions
  • Product-specific UI: LCR-II's rotary switch + 2-button menu, LCR-600's POS tax/discount engine, LCR.iQ's wireless pairing flow and SENSEiQ tank-level loop inputs
