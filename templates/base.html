Simulation built from Liquid Controls LectroCount engineering manuals (LCR-II, LCR 600, LCR.iQ/MASTERLOAD.iQ). Calibration math, VCF domain checks, multi-point validation rules, and the J8 pulser fault voltage table are modeled against the source manuals; VCF curve coefficients themselves are an engineering approximation since the manuals publish valid parameter ranges but not the underlying API table values. Original View recreates the real switch plate / keypad layout from the manuals' own dimensioned photos. Not a substitute for the real instrument or a Weights & Measures-traceable calibration. See README.md and SIMULATION_NOTES.md for full detail.
